# Our invitation

Upload index.html and .nojekyll to the root of your GitHub repository. In repository Settings > Pages, choose Deploy from a branch, main, and / (root).

This ZIP includes your current wording, photo, and uploaded music. No build step needed.

RSVP uses WhatsApp in this export because GitHub Pages does not process Netlify Forms. Set your WhatsApp number with country code in the editor before exporting. Guests must press Send in WhatsApp.

Motion needs HTTPS and a compatible phone, with permission granted. Touch alternatives are included.
